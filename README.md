# Todo CLI Sample

Ứng dụng quản lý công việc (To-Do List) đơn giản chạy trên dòng lệnh, viết bằng Python.
Đây là Sample Project dùng để làm quen với quy trình quản lý mã nguồn trên GitHub.

## Tính năng
- Xem danh sách công việc
- Thêm công việc mới
- Đánh dấu công việc đã hoàn thành
- Xóa công việc
- Dữ liệu được lưu vào file `tasks.json`

## Yêu cầu
- Python 3.8 trở lên

## Cách chạy
```bash
git clone https://github.com/<username>/todo-cli-sample.git
cd todo-cli-sample
python todo.py
```
